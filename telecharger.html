Installation

Cinq minutes, montre en main

  1. Déposer le plugin

    Copiez LoupGarouRPS-0.1.0-SNAPSHOT.jar (et ProtocolLib si vous l'utilisez) dans plugins/, puis démarrez le serveur une fois pour générer plugins/LoupGarouRPS/config.yml.

  2. Brancher le resource pack

    Deux options :

    A — hébergement externe. Mettez resourcepack.zip en ligne avec un lien direct (GitHub Release, mc-packs.net…) et collez-le dans resource-pack.url.

    B — le plugin l'héberge. Copiez le zip dans plugins/LoupGarouRPS/, laissez url vide et renseignez serveur-http.adresse-publique (et ouvrez le port 25597).

  3. Vider server.properties

    Laissez resource-pack= et resource-pack-sha1= vides : c'est le plugin qui envoie le pack, avec le bon SHA-1 et une URL qui change à chaque nouvelle version. Plus jamais de carte périmée en cache.

  4. Préparer une map

    Créez la map, enregistrez les maisons, le feu de camp et le point de vue du bûcher. Tout est expliqué dans le wiki, chapitre Maps.

  5. Ouvrir un salon

    /lg create game village 8 12 thiercelieux
/lg join village

    La partie démarre toute seule quand le salon est plein, ou avec /lg start village.

Journal des versions

La gazette

0.1.0 — première pré-version publique
  • 14 rôles distribuables + le titre de Capitaine, dans l'ordre officiel de la nuit.
  • Maisons, portes et paillassons comme cibles des pouvoirs nocturnes.
  • Nuits à l'aveugle, créneaux minutés, barre de compte à rebours.
  • Élection du Capitaine, débat, vote du village à main nue, départage par le Capitaine.
  • Mise en scène des morts : éclair, glas, carte accrochée au-dessus de la porte.
  • Chats privés : meute, amoureux (préfixe !), morts.
  • Resource pack envoyé par le plugin, skins par rôle via MineSkin.
  • Multi-salons, boussole des salons, lancement automatique, menu de réglage des durées.
